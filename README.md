# 매일 체크리스트

매일 하는 일(약 먹기, 운동, 물 마시기 등)을 체크하고, 한 달치를 한눈에 보는 웹 페이지입니다.

HTML 파일 하나로 되어 있어서 **설치할 것이 없습니다.**

## 기능

- 체크할 항목을 직접 추가하고 삭제
- 오늘 날짜가 자동으로 표시되고, 카드를 눌러서 체크
- `◀ ▶` 로 지난 날짜로 이동해서 빠뜨린 날 채우기
- 한 달치를 네모 그래프로 보기 (분홍 = 한 날, 회색 = 안 한 날)
- 창을 닫았다 열어도 기록 유지

## 기록은 어디에 저장되나요

기록은 **접속한 사람의 브라우저 안에만** 저장됩니다(localStorage).

- 서버로 전송되지 않고, 다른 사람에게 보이지 않습니다
- 접속하는 사람마다 각자 자기 기록이 따로 쌓입니다
- 같은 브라우저에서 "인터넷 사용 기록 삭제"를 하면 기록도 함께 지워집니다
- PC와 휴대폰의 기록은 서로 연동되지 않습니다
